# KADIN 360 Platform

Platform digital untuk anggota KADIN Indonesia yang berfungsi sebagai pusat komunikasi, kolaborasi, dan business matching dalam satu sistem terintegrasi. Platform ini dilengkapi dengan dukungan AI untuk memberikan insight dan rekomendasi yang membantu pengguna menemukan peluang bisnis, membangun koneksi, serta mendukung pengambilan keputusan secara lebih efektif.

## 🚀 Features

- Sistem komunikasi dan kolaborasi antar anggota
- Business matching platform
- Integrasi AI untuk insight dan rekomendasi
- Pengelolaan database menggunakan Supabase
- Manajemen data pengguna dan partner bisnis
  
## 🛠️ Tech Stack

- React.js
- Google AI Studio
- Supabase
- Tailwind CSS
- Vite

## 👨‍💻 Role

Backend Developer — berfokus pada perancangan dan pengelolaan database menggunakan Supabase serta mendukung integrasi data pada sistem.

## 📦 Installation

### Prerequisites
- Node.js
- npm

### Run Locally

1. Clone repository

```bash
git clone https://github.com/aduf2907/kadin-360-ver.git
```

2. Install dependencies

```bash
npm install
```

3. Setup environment variables

Buat file `.env.local` lalu tambahkan:

```env
GEMINI_API_KEY=your_api_key
```

4. Jalankan project

```bash
npm run dev
```
